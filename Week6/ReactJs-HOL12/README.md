# Ticket Booking App (simple React demo)

A minimal React app demonstrating conditional rendering of Login/Logout and greetings.

Quick start:

```bash
cd ReactJs-HOL12
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

Files:
- `src/App.jsx` - main app
- `src/components/Greeting.jsx` - greeting switch
- `src/components/LoginButton.jsx`
- `src/components/LogoutButton.jsx`

This matches the screenshots: guest sees "Please sign up." + `Login` button; logged-in user sees "Welcome back" + `Logout` button.

# StudentApp

A simple React app for the Student Management Portal lab.

## Features

- `Home`, `About`, and `Contact` class components
- Components rendered from `src/App.js`
- Uses `src/Components/` folder structure

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
3. Open `http://localhost:3000`
